# StudyTodo P0 安装指南（Windows + 免费 Apple ID）

这份文档带你完成一次性配置：把 StudyTodo 装进 iPhone，并设置好每 7 天的自动续签。
配置好之后，日常只用点"更新"即可，全程零费用。

> 前提：Windows 电脑（联网）、iPhone（iOS 26）、数据线、你自己的 Apple ID。
> 你的 Apple ID 密码只在你自己电脑的 AltServer 里输入，**不要发给任何人（包括我）**。

---

## 一、电脑端准备（一次）

1. 到苹果官网下载并安装：
   - **iTunes**（apple.com.cn/itunes）
   - **iCloud**（apple.com.cn/icloud）
   - 重要：必须用官网下载版，**不要用微软商店版**，否则连不上手机。
2. 分别打开一次 iTunes 和 iCloud，完成初始化，然后可以关掉。
3. 下载 **AltServer**：altstore.io → Windows 版 → 安装 → 从开始菜单启动。
   启动后任务栏托盘会出现一个"钻石"图标，这说明服务在运行。

## 二、把 AltStore 装进 iPhone（一次）

1. 用数据线把 iPhone 连到电脑。
2. iPhone 上弹出"要信任此电脑吗"→ 点**信任**，输锁屏密码。
3. 点托盘里的 AltServer 钻石图标 → **Install AltStore** → 选择你的设备。
4. 弹出登录框：
   - Apple ID 邮箱（自己的）
   - 密码
   - 手机上会弹出 6 位双重认证码，填进去
   - 如果提示输入"专用密码"：到 appleid.apple.com 生成一个 App 专用密码再填
5. iPhone 上打开：**设置 → 通用 → VPN 与设备管理** → 找到带你 Apple ID 的证书 → **信任**。
6. 桌面上出现 **AltStore** App 图标即成功。
7. 如果打开 App 时提示需要**开发者模式**：设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启手机。

## 三、安装 StudyTodo（每次更新时代替第 2 步）

1. 打开电脑浏览器，进入项目的 **GitHub → Actions → 最新一次 Build IPA** 运行记录。
2. 页面底部 **Artifacts** 下载 `StudyTodo-ipa.zip`，解压得到 `StudyTodo.ipa`。
3. 两种安装方式任选：
   - **方式 A（推荐）**：托盘 AltServer 图标 → **Install .ipa** → 选 `StudyTodo.ipa` → 选设备 → 用同一 Apple ID 签名。
   - **方式 B**：手机连电脑后，打开 iPhone 上的 AltStore → **My Apps** → 左上角 **+** → 从"文件"里选 `StudyTodo.ipa`。
4. 首次安装后：设置 → 通用 → VPN 与设备管理 → 信任 StudyTodo 的证书。
5. 打开 StudyTodo，完成 P0 冒烟测试（见下节）；回桌面长按空白处 → **+ 添加小组件** → 搜 StudyTodo。

## 四、P0 冒烟测试（装好后 3 分钟）

按 App 里的四个分区逐项检查：

| 检查项 | 通过标准 |
|---|---|
| ① 数据共享 | 点 Stepper 改数字 → 桌面小组件数字同步变化 |
| ② 实时倒计时 | App 和小组件里的倒计时都在秒级跳动 |
| ③ 通知权限 | 点"请求通知权限"→ 系统弹窗 → 状态变"已授权 ✅" |
| ④ AlarmKit | 显示 ✅ 或 ❌（告诉我们 iOS 26 SDK 链路是否通） |

把结果告诉我：哪一项没过、桌面小组件实际显示什么。

## 五、7 天续签（自动，基本无感）

免费 Apple ID 签名的 App 有效期 7 天。续签条件：

- 电脑开机，且 AltServer 在后台运行（托盘有钻石图标）
- 手机和电脑在同一 WiFi 下（没插线也可以）

满足条件时 AltStore 会**自动续签**，你什么都不用做。

建议把 AltServer 设为开机自启：Win+R → 输入 `shell:startup` → 把 AltServer 快捷方式拖进打开的文件夹。

**手动续签**（万一断签）：iPhone 上打开 AltStore → **My Apps** → **Refresh All**。
断签后的 App 会暂时打不开，**所有任务数据都还在**，续签后恢复。

## 六、免费账号的限制（知道就行）

- 同时最多 3 个签名 App（我们只有 1 个）
- 每个 Apple ID 每周最多创建 10 个 App ID
- 没有 TestFlight（分享给别人要 $99/年开发者账号，v1.1 再说）

## 七、常见报错

| 现象 | 处理 |
|---|---|
| AltServer 找不到设备 | 换数据线/换个 USB 口；确认 iTunes 是官网版；重新插拔并点"信任" |
| 安装时提示 0x8007xxxx | 卸载微软商店版 iTunes，装官网版；重启 AltServer |
| 双重认证码收不到 | 确认手机有网；改用 App 专用密码（appleid.apple.com） |
| 提示 "Max App IDs reached" | 本周额度用完了，等下周一或删掉旧签名 App |
| 小组件列表里搜不到 | 先打开一次 App，再回桌面长按添加；重启手机试试 |
| 小组件数字不联动 | 见 P0 测试表 ①，把现象告诉开发（可能是 App Group 权限问题） |
