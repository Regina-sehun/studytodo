# StudyTodo P0 安装指南（Windows + 免费 Apple ID）

> 首次安装约 30–45 分钟；之后每次更新约 5–10 分钟；日常续签全自动。
> 你的 Apple ID 密码只在本机 AltServer 里输入，不发给任何人（包括我）。

## 0. 开始前 3 分钟预检

| 项 | 要求 | 在哪看 |
|---|---|---|
| iPhone 系统 | iOS 26 及以上 | 设置 → 通用 → 关于本机 |
| Apple ID | 已开启双重认证 | 设置 → Apple 账户 → 登录与安全性 → 双重认证 |
| 电脑 | Windows 10/11，磁盘 ≥ 2 GB | — |
| 数据线 | 能传数据的线（非纯充电线） | — |
| 网络 | 手机与电脑同一 WiFi | — |
| 安装包 | 已在 `C:\Users\Regina0317\Downloads\StudyTodo.ipa` | 每轮更新会覆盖同名文件 |

## 1. 电脑：装官网版 iTunes 与 iCloud（约 10 分钟）

1. **先卸载商店版**（如果装过）：设置 → 应用 → 已安装的应用 → 搜 iTunes / iCloud / Apple 软件更新 / Apple Mobile Device Support → 逐个卸载。
2. 打开 **altstore.io** → Get AltStore → **Windows** 部分，按页面给出的官方链接下载 **iTunes** 和 **iCloud**。
   - 页面明确要求：**不要用 Microsoft Store 版**，否则 AltServer 连不上手机（报 0x8007xxxx）。
3. 先装 iTunes，再装 iCloud。
4. 启动一次 iTunes；启动一次 iCloud 并用你的 Apple ID 登录完成。
5. 之后两者可以关掉，但**不要卸载**。

## 2. 安装并启动 AltServer（约 5 分钟）

1. altstore.io 下载 **AltServer（Windows 版）** → 安装 → 从**开始菜单**启动（桌面快捷方式不运行没用）。
2. Windows 防火墙弹窗 → **允许**（专用和公用网络都勾）。
3. SmartScreen 拦截 → 更多信息 → **仍要运行**。
4. 任务栏托盘出现**钻石图标**（可能藏在 `^` 折叠区）。点开能看到 Install AltStore 之类的菜单，即服务正常。
5. 保持 AltServer 在后台运行——安装、更新、续签都需要它。

## 3. 连接 iPhone（约 5 分钟）

1. 数据线把 iPhone 连电脑。
2. iPhone 弹"要信任此电脑吗" → **信任** → 输锁屏密码。
3. 打开 iTunes，确认能看到你的设备。
   - 看不到：换线 / 换 USB 口 / 重启 iTunes 再试。
4. iTunes 如果提示更新设备软件，按提示更新。

## 4. 把 AltStore 装进 iPhone（约 10 分钟，一次性的）

1. 点托盘钻石图标 → **Install AltStore** → 选择你的设备（如 "Regina 的 iPhone"）。
2. 弹窗输入 **Apple ID 邮箱** → 下一步。
3. 输入密码。若提示需要"专用密码"：
   - 浏览器打开 appleid.apple.com → 登录 → 找到 **App 专用密码** → 生成一个（名字随意）→ 复制回弹窗。
4. 手机弹出 6 位**双重认证码** → 填入。
5. 等 1–2 分钟，iPhone 桌面出现 **AltStore** 图标。
6. 首次打开如提示"未受信任的开发者"：设置 → 通用 → VPN 与设备管理 → 开发者 App → **AltStore → 信任**。
7. 如提示开启**开发者模式**：设置 → 隐私与安全性 → 开发者模式 → 打开 → **重启手机**生效。
8. 打开 AltStore 能进入即成功（左上角能看到账户）。

## 5. 安装 StudyTodo（约 5 分钟）

1. 托盘钻石 → **Install .ipa** → 选择 **`C:\Users\Regina0317\Downloads\StudyTodo.ipa`** → 选择设备。
   - 菜单里没有 "Install .ipa"：把 AltServer 升级到最新版；或直接用第 8 节 Sideloadly 方案。
2. 再次输入 Apple ID 密码 + 手机 6 位验证码。
3. 等待 1–2 分钟，桌面出现 **StudyTodo**。
4. 首次打开前信任证书：设置 → 通用 → VPN 与设备管理 → 找到 **StudyTodo** → 信任。
5. 若弹"开发者模式未开启"→ 按 4.7 操作。
6. 打开 App，应看到 **StudyTodo · P0** 四个小节：数据共享、实时倒计时、通知权限、AlarmKit。

## 6. 添加桌面小组件（约 3 分钟）

1. 先确保 StudyTodo **打开过一次**。
2. 回桌面，**长按空白处**直到图标抖动。
3. 点左上角 **+** → 搜索 **StudyTodo** → 选中 → 选择 **小（2×2）** 或 **中（4×2）** → 添加小组件。
4. 建议放在第一页，方便测试。

## 7. P0 冒烟测试（约 3 分钟）

| 项 | 怎么测 | 通过标准 | 失败可能意味着 |
|---|---|---|---|
| ① 数据共享 | App 里点 Stepper 的 **+** 3 次 → 回桌面看小组件 | 几秒内"共享计数"变成 3；再点几次双向验证 | 一直不变 → 免费签名下 App Group 不可用（关键风险），告诉我 |
| ② 实时倒计时 | 盯着 App 和小组件里的计时文本 1 分钟 | 两边都**秒级跳动**（小组件不用刷新也会自己跳） | 小组件静止 → 渲染/刷新问题，告诉我 |
| ③ 通知权限 | 点"请求通知权限"→ 系统弹窗 → **允许** | 状态变"已授权 ✅" | 不弹/被拒，把现象告诉我 |
| ④ AlarmKit | 直接看文字 | ✅ 或 ❌ 都**如实报告**（P0 只检测；真闹钟 P3 才接入） | — |

## 8. 备选方案：Sideloadly（AltStore 装不上时用）

1. **sideloadly.io** 下载并安装。
2. 连线、信任电脑（同第 3 节）。
3. 打开 Sideloadly：IPA 选 `Downloads\StudyTodo.ipa`；Apple ID 填邮箱；点 **Start**；输入 2FA。
4. 信任证书 + 开发者模式（同第 5 节）。
5. 缺点：**不会自动续签**，每 7 天重跑一次（覆盖安装，数据保留）。
   想要自动续签就再回来装 AltStore。
6. 进阶：SideStore 可以在手机端自续签（电脑只用于首次安装），需要时我们单独开专题。

## 9. 7 天续签设置（配一次，之后无感）

1. **AltServer 开机自启**：Win+R → 输入 `shell:startup` → 把 AltServer 快捷方式拖进打开的文件夹。
2. 续签条件：**电脑开机 + AltServer 运行 + 手机与电脑同一 WiFi**。满足即自动续签。
3. iPhone：设置 → 通用 → 后台 App 刷新 → **AltStore 打开**。
4. 手动续签：iPhone 打开 AltStore → **My Apps** → **Refresh All**。
5. 断签表现：App 图标变灰/打不开，**所有任务数据都还在**，续签后恢复。7 天内至少续签一次即可。

## 10. 常见问题速查

| 现象 | 处理 |
|---|---|
| AltServer 找不到设备 | 换线/换 USB 口；确认 iTunes 是官网版；重新插拔并点"信任" |
| 安装报 0x8007xxxx | 卸载微软商店版 iTunes/iCloud，装官网版；重启 AltServer |
| 双重认证码收不到 | 确认手机有网；改用 App 专用密码（appleid.apple.com） |
| 打开 App 提示"未受信任的开发者" | 设置 → 通用 → VPN 与设备管理 → 信任对应证书 |
| 提示需要开发者模式 | 设置 → 隐私与安全性 → 开发者模式 → 开 → 重启手机 |
| AltStore 打开闪退 | 重新用 AltServer 安装 AltStore |
| 小组件画廊搜不到 StudyTodo | 先打开一次 App；重启手机再试 |
| 小组件数字不联动 | 记下现象告诉我（可能是 App Group 权限问题） |
| "Max App IDs reached" | 本周额度用完，删掉旧签名 App 或等下周一 |
| "Unable to Install" | 多半是 7 天到了/证书失效，重新安装或续签 |
